# UnBot Custom

Аддон для WoW WotLK 3.3.5a (Interface 30300), рассчитанный на частный сервер с Playerbot/UnBot. Версия публичного снимка: **6.44.10-public.1**.

Управление альтами и ботами, сохранённые наборы экипировки и талантов, сбор групп, настройки поведения и помощники для отдельных боёв. Серверные команды и поведение могут отличаться на других серверах.

## Установка

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив.
2. Скопируйте вложенную папку **UnBotCustom** в **World of Warcraft/Interface/AddOns/**. Файл UnBotCustom.toc должен находиться непосредственно внутри неё.
3. Отключите прежний UnBot в списке модификаций, включите UnBot Custom и выполните **/reload**.
4. Для переноса настроек прочитайте **INSTALL_RU.txt**. Не удаляйте папку WTF и свои SavedVariables.

## Команды

- **/unbot** — основное меню.
- **/ubsetups** — настройка альтов и наборов.
- **/ubsetups group <название>** — собрать сохранённую группу и применить назначенные наборы.
- **/ubsetups stop** — остановить выполняющееся действие.
- **/ubloot** — настройки добычи.

Начатая сборка и применение наборов продолжаются после закрытия окна. Действия, требующие ручного подтверждения обмена, подтверждает игрок. При сборе группы используется однократное снятие игрока с маунта; причина прежних сбоев на маунтах окончательно не установлена.

## Публичный снимок

Исходники основаны на выпуске 6.44.10. Из копии удалены личные привязки аккаунтов и персонажей, а также bootstrap личной сети обмена. Общая база обычных ботов сохранена. Пользовательские SavedVariables, журналы и рабочие материалы в репозиторий не включены. Установленный аддон эта публикация не изменяет.
